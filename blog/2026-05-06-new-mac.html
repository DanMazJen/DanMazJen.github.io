Congrats with the your Mac!

It’s great getting a new computer - it’s faster, has more CPU/GPU, and it’s a great way to “start fresh”. However… fresh starts can be tedious, cumbersome and frustrating if you have to make a comprehensive setup. This blog post is for future me (and maybe you), if you need to start from scratch with your Mac OS.

Setting up a Mac

We need some basic functionality and a nice way to organize and manage software:

  1. First, install xcode — a collection of tools/software for Mac devs.
  2. Second, the infamous curl for internet API from the terminal.
  3. Finally, homebrew, the package manager for Mac OS.

For all the tools, we’ll use the terminal. Mac OS is a unix system and uses zsh as default.

TipThe terminal

A terminal uses an IDE (iTerm2) and a coding language underneath (bash/zsh). It’s benefinical to learn quickly!

Step 1: xcode-select

Run:

xcode-select --install

Now, we should have a C-compiler, git, and many more most-haves for programming.

Check that you have git by running:

git --version

Step 2: Homebrew

To manage most software/apps, we’ll use Homebrew:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Follow “Next Steps”

echo >>

Step 3: Happy brew install

Finally, we’ll make a large brew install for all the most important software we want to update regularly and manage via the package manager:

Github CLI:

brew install gh

Check it with:

gh auth login

zsh instead of bash

brew install ---cask zsh

Terminal

brew install ---cask iterm2

R version manager

brew tap r-lib/rig
brew install ---cask rig
rig add release

Quarto CLI

brew install ---cask quarto

Positron IDE

brew install ---cask positron

Plugin for zsh

brew install zsh-autosuggestions 
brew install zsh-syntax-highlighting brew
brew install autojump

Agnostic script/workflow code

brew install just

URL tester

brew install lychee

Python management

brew install uv

Inexpensable system navigation and shortcuts for Mac OS

brew install --cask raycast

Team communication

install --cask discord

Snippet management

install --cask espanso

Notes in markdown

brew install --cask obsidian

Blasing fast database

brew install duckdb

Windows app for DST working on server

brew install --cask windows-app

A collection of fonts needed by R/quarto on Mac

brew install --cask xquartz

A note on Rust

Don’t install Rust using Brew!

Simply, use rustup, run:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Then, update using:

rustup update

You also get cargo for free:

cargo --version
